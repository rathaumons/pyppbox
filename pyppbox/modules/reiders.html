FaceNet | MyFaceNet#

TensorFlow-based face recognition. See Devices for device behavior.

class pyppbox.modules.reiders.facenet.MyFaceNet(cfg, auto_load=False)[source]#

Identify the first detected face using MTCNN, FaceNet embeddings, and an SVM.

For direct use, call load_classifier() before recognize() or construct with auto_load=True. Loading creates a TensorFlow session and loads MTCNN, FaceNet weights, and the classifier pickle with its ordered class names.

TensorFlow selects devices using its installed build and available hardware; there is no device config key. cfg.gpu_mem controls the session’s GPU memory fraction, not CPU/GPU selection. The GUI’s last parameter row shows device and auto by TensorFlow before Save.

Load or replace the instance’s identity classifier and supporting state.

Read the classifier and ordered labels from the configured pickle. The companion .txt file is a readable training output; it is not required or used for recognition. Recognize the first MTCNN-detected face in an image.

Parameters:

  • img (numpy.ndarray) – Nonempty three-channel image crop. Initialize the classifier before calling this method directly. The first face box is cropped and resized for the embedding network.

  • is_bgr (bool) – Defaults to True. Convert OpenCV BGR input to RGB when True; False means the crop is already RGB.

Returns:

  • str – Identity label at or above the threshold, the configured unknown ID below it, or the configured error ID when no prediction is available.

  • float – Classifier confidence on a 0-100 scale, including below-threshold results; 0.0 when no prediction is available.

Notes

This method does not catch image-processing or inference exceptions. The returned error ID is not a substitute for handling exceptions in direct use.

train_classifier(C=1.0, kernel='rbf', probability=True, decision_function_shape='ovr')[source]#

Train an identity SVM from pretrained embeddings and write its files.

Parameters:

  • C (float) – Defaults to 1.0. Regularization parameter, passed to sklearn’s SVC(C=C, ...).

  • kernel (str) – Defaults to 'rbf'. Embedding-feature kernel, for example 'linear', 'poly', 'rbf', or 'sigmoid'. This method supplies feature vectors, not a precomputed kernel matrix.

  • probability (bool) – Defaults to True. Whether to use probability estimates, passed to sklearn’s SVC(probability=probability, ...).

  • decision_function_shape (str) – Defaults to 'ovr'. Choice of function: 'ovo' or 'ovr', passed to sklearn’s SVC(decision_function_shape=decision_function_shape, ...).

Notes

The training directory must contain image-only identity subdirectories, with at least two identities. This trains the SVM, not the embedding network. It overwrites the configured .pkl and companion .txt label file and returns None. Output directories must exist. Keep probability=True for classifiers used by recognize(), which calls predict_proba(). Call load_classifier() after training to use the written classifier in this existing instance.

Identify a cropped person using Torchreid embeddings and a saved identity SVM.

Construction loads the feature extractor even with auto_load=False. For direct use, call load_classifier() before recognize() or construct with auto_load=True. Each instance holds its own extractor and classifier.

cfg.device is passed to the PyTorch feature extractor. The GUI has an editable device dropdown; CPU, CUDA/indexed GPU, and MPS choices require matching runtime/hardware support. Numeric indices normalize to cuda:N; the literal auto is not accepted.

recognize_batch(images, is_bgr=True, batch_size=16)[source]#

Recognize cropped people in bounded, ordered inference batches.

Parameters:

  • images (object) – Iterable of nonempty three-channel image arrays, in result order. May be a generator. Initialize the classifier first, as for recognize(). Each image receives the same BGR conversion and extractor preprocessing as the scalar path.

  • is_bgr (bool) – Defaults to True. False means the supplied crops are already RGB.

  • batch_size (int) – Positive maximum crops per extractor/classifier call; defaults to 16. A value of one, or a final singleton, uses scalar recognize(). Only one chunk of temporary images/features is prepared at a time.

Returns:

One identity/confidence pair per input, in order. Confidence remains on the 0-100 scale, including unknown results. Empty input returns [].

Return type:

list[tuple[str, float]]

Notes

Batch arithmetic can slightly change confidence values. Results within 0.1 percentage points of the configured threshold, or with a winner margin at most 0.2 points, are rechecked using scalar recognition. This protects nearby decisions; it is not a universal numerical-error bound for custom models. Invalid images, backend errors, or inconsistent outputs raise without a partial result. The pipeline handles those failures per person. Result-list storage grows with input length; temporary inference storage is chunk-bounded.

ArcFace and AdaFace#

ArcFace R50 and AdaFace IR18 use ONNX Runtime with SCRFD face detection and 112x112 alignment. Install the optional runtime and the selected model/data wheel from 🚀 Getting Started. Each wheel supplies its own detector, embedding model, and GTA V identity classifier. CPU is the default; see Devices for CUDA selection.

Select either reider in the GUI or pipeline:

from pyppbox.ppb.mt import MT

with MT() as pipeline:
    pipeline.setMainReIDer('ArcFace')  # or 'AdaFace'
    # Pass detected/tracked people to pipeline.reidPeople().

For one face image:

from pyppbox.config.myconfig import RCFGArcFace
from pyppbox.modules.reiders.onnxface import MyArcFace

backend = MyArcFace(RCFGArcFace(relative_to_pyppbox_root=True), auto_load=True)
try:
    identity, confidence = backend.recognize_file('face.jpg')
finally:
    backend.close()

Use RCFGAdaFace and MyAdaFace for AdaFace. extract_embedding(image) returns a normalized embedding or None when no face is detected. embed_aligned(image) accepts a BGR 112x112 image and skips detection.

Training identities#

Put JPG/PNG training images in one subdirectory per identity, then call trainReIDClassifier() with the selected reider, training directory, and output classifier path. This trains an SVM while keeping the embedding model frozen. See Example 12: Retrain GTA V classifiers for all supported reiders and Example 18: Recognize faces and train an ArcFace or AdaFace classifier for complete examples.

Classifiers are specific to their backend, model, and preprocessing settings. Incompatible classifiers are rejected. Load only trusted pickle files. Confidence is an SVM probability on a 0–100 scale; min_confidence uses 0–1.

The SCRFD adapter includes MIT-licensed InsightFace code; see NOTICE and licenses/InsightFace-MIT.txt. The InsightFace Python package is not required. Model weights have separate terms; see the notices in the selected data wheel.

Optional ArcFace/AdaFace ONNX inference with SCRFD five-point alignment.

Importing this module does not import ONNX Runtime. Models are local files and are never downloaded implicitly. Classifiers are backend- and checkpoint-specific; FaceNet pickles cannot be reused.

class pyppbox.modules.reiders.onnxface.ONNXFace(cfg, auto_load=False)[source]#

Bases: object

Shared single-face recognizer preserving pyppbox’s (label, percent) API.

Use load_classifier before recognize. extract_embedding can be used without a classifier; it returns None when no face is detected. The largest detected face is selected from a crop, aligned to 112x112 using SCRFD keypoints, then embedded and L2-normalized. Confidence is the identity SVM’s probability estimate, not the cosine score or a liveness measurement. Instances own their sessions and are not intended for concurrent calls.

cfg.device selects CPU (default), cuda, or cuda:N. Configuration normalizes numeric GPU indices; the GUI offers an editable CPU/CUDA dropdown. mps and auto are not supported by these adapters. An unavailable or failed CUDA provider raises instead of silently selecting CPU at initialization.
