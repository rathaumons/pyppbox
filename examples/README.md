Run the scripts with this `examples/` directory as your working directory, so the
relative `data/`, `cfg/`, and `single_config/` paths resolve correctly.

For examples 3, 4, 5, 11, and 13, replace the `C:/pyppbox_v3/` placeholder in the
script or its custom config files with your installed `pyppbox` directory. You can
find it with `python -c "import os, pyppbox; print(os.path.dirname(pyppbox.__file__))"`.
