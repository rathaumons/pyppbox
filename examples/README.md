# pyppbox examples

Install pyppbox and the required model/data wheels using [GETSTARTED](../GETSTARTED.md).
Run the scripts with this directory as the working directory, for example:

```sh
cd examples
python example_01_basic.py
```

See the [example guide](https://rathaumons.github.io/pyppbox/examples.html) for
module requirements, configuration, and examples 1–18.
